# 首页完善与验收清单

目标：优化和补全首页全部可见功能，形成清晰、可操作、可持久化、有反馈的使用闭环。当前审计发现的占位功能不能作为已完成项。

## 验收范围

- [ ] 任务：按当前日期/清单新建，可靠解析明确日期时间；编辑标题、备注、日期、时间、状态、优先级；置顶、复制、移动、删除、恢复、永久删除及撤销/确认。
- [ ] 子任务：新增、编辑、勾选完成、删除；兼容旧字符串数据。
- [ ] 清单：新增、重命名校验、删除并保留正确归属；分组管理，完成/放弃状态和计数一致。
- [ ] 查找：跨清单全文搜索、跳转详情、标签筛选、优先级和状态过滤、排序与筛选清除。
- [ ] 日历：月/周/日/议程真实切换与前后导航，选日创建，拖动改期，未安排任务独立展示。
- [ ] 时间线：逾期、今天、将来、未安排任务无重复或遗漏，支持改期与详情。
- [ ] 四象限：重要/紧急独立维度，拖动和读取规则一致，已结束任务不混入待办象限。
- [ ] 看板：待处理、进行中、完成/放弃状态移动，快捷创建与详情，键盘可操作。
- [ ] 提醒与通知：设置有效提醒时间、到期提醒、可查看/处理通知，明确应用运行条件。
- [ ] 重复任务：按日/周/月规则产生后续任务，重复完成/撤销不生成多份；日期边界和 MCP 状态更新一致。
- [ ] 模板：保存、浏览、创建、删除；活动记录可查询，附件/备注/格式化等可见入口完成真实操作。
- [ ] 同步：显示实际加载/保存/错误状态，手动刷新与重试真实有效；刷新和 MCP 修改后正确恢复。
- [ ] 引导：移除不实的会员、跨平台协作等产品承诺，帮助与快捷键对应实际能力。
- [ ] 视觉与无障碍：空详情、窄窗口、亮/暗主题、焦点、键盘、空列表、错误提示和长文本均可用。
- [ ] 验证：业务边界单元测试、现有同步回归测试、构建、隔离测试数据的浏览器端交互验证；未覆盖项保持未完成。

## 当前发现

现有首页是单文件页面。搜索受当前清单限制；工具视图选择会被列表筛选覆盖；创建时间默认与选中日期不一致；四象限存储和显示映射不同；周/日翻页仅改变月份；未安排任务在时间线重复；子任务点击直接删除；清单重命名/删除未同步全部归属字段；置顶不参与排序；提醒、重复、模板、附件和动态缺少完整流程。后续以实际实现和运行结果更新验收状态。

## 第二轮实现与提交验证（2026-09-13）

已接入重复任务生命周期、到期站内提醒与通知处理、模板库、活动记录、附件、备注格式与预览、本地评论、清单分组和回收站批量处理。新增标题校验，浏览器保存失败会保留页面修改并允许重试；清单和任务使用同一份浏览器缓存，减少部分保存风险。

提交前修复了筛选状态下新建任务不可见时的定位、视图创建失败仍清空草稿、目标分组覆盖手选日期等问题；明确选择日期时优先使用选择值，未明确选择时保留自然语言日期解析。

前端与 Rust 持久化层均处理重复任务，完成后生成唯一后续实例；撤销再完成、后续实例被编辑或永久删除时不会重复生成或覆盖。MCP 创建和更新工具支持重复规则、提醒、重要、紧急和置顶字段，清单改名及删除保留其他归属和分组元数据。

验证结果：
- `node --test tests/*.test.js`：37 项通过，覆盖同步重试、任务筛选与视图归属、模板与附件限制、分组和回收站确认快照、重复日期边界、提醒状态。
- `cargo test --offline --lib`：21 项通过，覆盖 SQLite 持久化、并发修改、重复任务、MCP HTTP、脚本启动停止及子进程清理；使用临时数据库与测试进程。
- `npm run build`：生产构建通过；仍有既有浏览器兼容数据过期与大体积代码块提示。

本次提交不表示首页已通过全部验收。后续仍需完成全部新模块的浏览器交互验证，以及亮暗主题和宽窄窗口检查。只读审查还记录了待处理项：分组标题加号的创建动作、清单活动按时间聚合、打印内容与复制分享结果、备注预览返回编辑的定位，以及跨午夜后“今天”视图日期更新。保持上方整体验收项未勾选，避免把实现与完整验证混为一谈。已安装桌面应用尚未替换为本轮构建。
