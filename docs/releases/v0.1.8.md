## 新增项目总管

- 在统一对话中识别项目、拆分需求、分派 Codex Worker，并自动收回执行结果。
- 不同项目的 Worker 并行执行；同一目录及父子目录排队，最多同时运行三个 Worker。
- 保存任务账本和会话 ID，支持继续追问、执行中追加要求、停止任务和操作审批。
- 总管可独立选择 Codex 模型与推理强度，也可直接配置 OpenAI 兼容 API、模型 ID 和结构化输出格式。
- API 密钥保存在系统凭据库，提供模型列表读取和连接测试。

## 修正项目导入

- 工作区默认按直属文件夹导入，显示真实目录名，不再把示例子包混入顶层项目。
- 支持 Swift、Rust、Go、Python 等非 Node 项目，并保留可选的“包含嵌套项目”扫描方式。
- Node 包名保留为补充信息，并兼容已有的编辑器和 Node 版本偏好。

## 使用方式

项目 Worker 需要本机安装并登录 Codex CLI。打开“总管 → 连接设置”检测或选择 Codex 可执行文件，再通过顶部模型按钮配置总管。

从旧版升级后，请刷新对应工作区，以使用新的导入规则。第三方 API 当前支持 OpenAI 兼容 Chat Completions。应用完全退出后停止任务跟进；中断任务不会撤销已经产生的文件修改。

使用说明：[项目总管](https://github.com/black-lattice/runproject/blob/v0.1.8/docs/AGENT_MANAGER.md)。
